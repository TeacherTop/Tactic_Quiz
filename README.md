# Ближе всех

Playable-прототип викторины в духе числового раунда Triviador: игрок против двух ботов, сначала ставка на точное число, затем серия вопросов A-D.

## Что уже есть

- Vite + React + TypeScript без бэкенда.
- Числовой раунд с таймером, ботами, сравнением по абсолютной ошибке и тай-брейком по времени ответа.
- Квиз из пяти случайных вопросов, где порядок хода задаётся результатом числового раунда.
- Очки за числовой раунд, правильность и скорость в квизе.
- Экран раскрытия и финальные результаты с повтором партии.

## Команды

```bash
npm run dev
npm run build
npm run lint
```

Проверка первого этапа: запустить `npm run dev`, пройти путь старт -> числовая ставка -> раскрытие -> 5 квиз-вопросов -> итоги.
